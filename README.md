## 🌊 About This Project

**Rekawa** is a pristine coastal village on the southern tip of Sri Lanka, home to one of the most important sea turtle nesting beaches in Asia. Every year, five endangered species of sea turtles — Green, Hawksbill, Leatherback, Loggerhead, and Olive Ridley — emerge from the Indian Ocean to nest on its moonlit shores.

This website was built to **share that magic with the world** — giving international tourists a vivid, immersive preview of what awaits them at Rekawa, and inspiring them to experience this wonder responsibly.

## ✨ Key Features

### 🌊 3D Underwater Swimming Scene
A real-time WebGL underwater environment where photorealistic sea turtles swim through sunlit ocean water — complete with god rays, rising bubbles, swaying sea kelp, and a sandy seabed.

### 🐢 Turtle Swim Overlay
20 hand-crafted SVG sea turtles of all 5 real species, each with authentic shell patterns and natural colors, swimming freely across the full screen in both directions with realistic bobbing and flipper-flap animations.

### 🌙 3D Night Beach Nesting Scene
An atmospheric moonlit beach recreation featuring mother turtles crawling ashore and baby hatchlings racing toward the sea — all rendered in real-time 3D.

### 🔬 3D Turtle Studio Inspector
An interactive 360° model inspector where users can examine a detailed sea turtle up close, adjust shell wetness, flipper motion speed, and bump texture depth in real time.

### 🎭 Ethical Night Turtle Watch Simulator
An interactive simulator that educates tourists about the strict ethical guidelines required when observing nesting turtles — simulating a real patrol experience.

### 🛶 Rekawa Lagoon Kayak & Wildlife Explorer
An interactive lagoon map featuring the mangrove waterways, bird species, and marine wildlife that make Rekawa's ecosystem uniquely diverse.

### 📸 High-Resolution Photo Gallery
A stunning photo grid and 360° panorama viewer showcasing Rekawa's landscapes, wildlife, and culture in vivid detail.

### 🗓️ Foreign Tourist Travel Guide
A comprehensive travel planner for international visitors — including peak nesting seasons, accommodation guides, local transport, and conservation tips.

### 🎵 Ocean Soundscape Player
A Web Audio API–powered ambient sound generator that plays authentic ocean waves, night insects, and beach ambiance — bringing Rekawa's atmosphere directly to the visitor's ears.

## 🚀 Getting Started

### Prerequisites
- Node.js 18+ installed
- npm or yarn package manager

### Installation

```bash
# Clone the repository
git clone https://github.com/VidumuniTharika/TURTLE-WATCHING-WEBSITE-FOR-TOURISM.git

# Navigate into the project
cd TURTLE-WATCHING-WEBSITE-FOR-TOURISM

# Install dependencies
npm install

# Start the development server
npm run dev
```

Then open your browser and visit:
```
http://localhost:3000
```

## 📍 About Rekawa, Sri Lanka

- **Location:** Tangalle, Southern Province, Sri Lanka
- **Coordinates:** 6.0°N, 80.8°E
- **Best Visit Season:** April – September (peak nesting)
- **Nearest Airport:** Mattala Rajapaksa International (HRI) — 45 km
- **Conservation Body:** Rekawa Turtle Conservation Project

---

## 🌿 Ethical Tourism

This website promotes **responsible eco-tourism**. Visitors to Rekawa are asked to:
- Follow all ranger instructions during turtle watches
- Never use white flashlights on the beach at night
- Maintain a safe distance from nesting females and hatchlings
- Never touch or pick up turtles
- Support local conservation initiatives
